# Use cases

[English](usecases.md) | [日本語](usecases.ja.md)

This project lets you study how a spiral of silence emerges (or fails to) on a social network, by simulating Noelle-Neumann's two-layer opinion dynamics and measuring the asymmetry between a louder majority and a silenced minority.

## What you can do

- **Reproduce the train-test asymmetry.** Run the socialism scenario and watch the winning camp voice far more than the losing camp, with the public discourse `q̂` diverging from the true support `q` — the spiral and its perceived/actual gap.
  → [CLI `run`](cli.md), [Visualization `visualize`](visualization.md)

- **Map the boundary of a global spiral.** Sweep media homogeneity `η_m` against network rewiring `β` (and degree `k`, support `q`) to find where a global spiral switches on, and confirm that higher media homogeneity broadens the spiral — the operational form of "the mass media create public opinion."
  → [CLI `sweep`](cli.md), [Visualization `visualize-sweep`](visualization.md)

- **Test the future-assessment hypothesis (H5).** Vary the future weight `α` and see the future-assessment gap grow — the minority's pre-emptive voicing or silence is driven by where it thinks the climate is heading, not only where it is now.
  → [CLI `sweep --alpha-values`](cli.md)

- **Probe the hardcore boundary.** Raise `hardcore-frac` and watch a mobilized, low-threshold minority refuse to be silenced, partially halting the spiral.
  → [CLI `run --hardcore-frac`](cli.md), [Reproduction](reproduction.md)

- **Explore anonymity counterfactuals.** Raise the anonymity coefficient `α_a` (which shrinks the fear of isolation) to see the spiral weaken — a contemporary online-discourse reading of the theory.
  → [CLI `sweep --alpha-a-values`](cli.md)

- **Compare a rule decision against an LLM introspection.** Optionally swap the logistic voice rule for a language model that introspects the fear of isolation, and compare the output distributions.
  → [CLI LLM ablation](cli.md)

- **Check the model against the paper.** Run `reproduce` to score the model against the Table 1–5 Allensbach-survey anchors.
  → [Reproduction](reproduction.md)
