## 指標の定義

- **`majority_voice_ratio`**: 多数派陣営の自陣営発言オッズ ÷ 少数派陣営のオッズ の対数．符号ではなく役割 (多数派 vs 少数派) で定義するため，どちらの符号が多数派でも正で読める．log-OR > 0 が沈黙の螺旋の signature (H1)．
- **`future_assessment_gap`**: 多数派の平均未来気候知覚 − 少数派の平均．多数派は自側の未来を楽観し，少数派は悲観する (H5)．
- **`hardcore_survival`**: 少数派ハードコア (低閾値・動員度の高い少数派) のうち自陣営として発言を続ける比．`hardcore_frac` を上げると螺旋に抗する声高な少数派が現れる — 論文の「53--61% 多数派より発言意欲の高い 17--25% 少数派」．
- **`perceived_minus_actual`** (`q̂ − q`): 発言者の見かけ支持率と真の私的支持率の乖離 — 創発する H3 の歪み．

太字の 3 アンカーがモデルの較正目標である．Table-1/2/4 の絶対 % 帯は目安であり，ABM は調査スナップショットでなく動的均衡まで回るため，絶対発言水準は調査クロスセクションを上回り得る一方で，**非対称** (log-OR) と**未来ギャップ**は帯内に収まる．
