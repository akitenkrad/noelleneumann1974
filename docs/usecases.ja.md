# ユースケース

[English](usecases.md) | [日本語](usecases.ja.md)

本プロジェクトは，Noelle-Neumann の二層意見動学をシミュレートし，声高な多数派と沈黙する少数派の非対称を測ることで，社会的網の上で沈黙の螺旋がいつ出現する (しない) かを調べられる．

## できること

- **列車テスト非対称の再現**: 社会主義シナリオを実行し，勝ち組が負け組よりはるかに発言すること，公的言説 `q̂` が真の支持率 `q` から乖離すること — 螺旋とその知覚/実乖離 — を観察する．
  → [CLI `run`](cli.ja.md)，[可視化 `visualize`](visualization.ja.md)

- **大域的螺旋の境界マップ**: 媒体均質性 `η_m` × 網再配線率 `β` (次数 `k`・支持率 `q`) を走査し，大域的螺旋が立ち上がる境界を特定する．媒体均質性が高いほど螺旋が広がる — 「マスメディアが世論を創出する」の操作的形．
  → [CLI `sweep`](cli.ja.md)，[可視化 `visualize-sweep`](visualization.ja.md)

- **未来評価仮説 (H5) の検証**: 未来重み `α` を変えて未来評価ギャップが拡大するのを見る — 少数派の先行発言 / 沈黙は，現在だけでなく気候の向かう先で駆動される．
  → [CLI `sweep --alpha-values`](cli.ja.md)

- **ハードコア境界の探索**: `hardcore-frac` を上げ，沈黙を拒む動員度の高い低閾値少数派が螺旋を部分的に止めるのを見る．
  → [CLI `run --hardcore-frac`](cli.ja.md)，[再現](reproduction.ja.md)

- **匿名条件の反事実**: 匿名係数 `α_a` (孤立恐怖を縮減) を上げ，螺旋が弱まるのを見る — 理論の現代的オンライン言説への読み替え．
  → [CLI `sweep --alpha-a-values`](cli.ja.md)

- **ルール決定 vs LLM 内省の比較**: ロジスティック発言ルールを，孤立の恐怖を内省する言語モデルに任意で差し替え，出力分布を比較する．
  → [CLI LLM ablation](cli.ja.md)

- **論文との照合**: `reproduce` を実行し，Table 1--5 のアレンスバッハ調査アンカーでモデルを採点する．
  → [再現](reproduction.ja.md)
